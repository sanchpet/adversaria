# ADR-0008 — Два рода шаблонов: Templater ≠ agent-скелет

## Контекст

Заготовка заметки нужна двум разным потребителям: инженеру, который создаёт файл в Obsidian горячей клавишей, и агенту, который создаёт файл сам. Их требования расходятся: первому нужны подстановки даты и автоперемещение файла, второму — чистая структура без исполняемого кода, который он не выполняет и который засоряет результат.

## Решение

**Разводятся два каталога с разными правилами.**

| | `80-kernel/templates/` | `80-kernel/scaffolds/` |
|---|---|---|
| Потребитель | инженер (Obsidian + Templater) | агент |
| Содержит | код Templater (`<% %>`), подстановки, автоперемещение | чистый markdown с плейсхолдерами `<...>` |
| Правит | engineer-writer | agent-writer |
| Проверяется frontmatter-гейтом | нет (исключён) | нет (исключён) |

Скелет **не содержит** исполняемого кода: агент подставляет значения сам и знает контекст лучше любой подстановки. Шаблон Templater **не используется** агентом: он оставил бы в файле неисполненные теги.

## Альтернативы

- **Один каталог с двумя видами файлов** — отклонён: различие остаётся в голове, а неисполненные теги Templater всплывают в созданных агентом карточках.
- **Только Templater, агент вызывает его** — отклонён: агент не может исполнить плагин редактора; пришлось бы воспроизводить его логику.
- **Только скелеты, инженер копирует руками** — отклонён: теряется единственная вещь, ради которой Templater и стоит, — автоматическая дата, имя и перемещение файла.

## Последствия

- **+** Каждый потребитель получает форму, пригодную для его способа создания файла.
- **+** Форма живёт отдельно от процедуры: скилл ссылается на скелет, а не несёт разметку в себе.
- **−** Две заготовки на одну сущность там, где её создают оба (день, заметка) — расходятся, если править одну. Правило: смысловое поле добавляется в обе за один коммит.
