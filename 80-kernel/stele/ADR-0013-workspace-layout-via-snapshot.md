# ADR-0013 — Раскладка Obsidian: именованный снимок, не живой `workspace.json`

## Контекст

Раскладка панелей — часть рабочего места, и на новой машине её хочется получить готовой (INV-1). Живой `.obsidian/workspace.json` для этого непригоден: Obsidian переписывает его каждую сессию, а при работе с двух машин это даёт конфликты слияния на машинном JSON — файле, который человек разрешать не должен.

Без записанного решения строка `.obsidian/workspace.json` в `.gitignore` выглядит произволом и будет снята первым, кому она помешает.

## Решение

- **Живой `workspace.json` — в `.gitignore`**: локальное состояние UI, не состояние системы.
- **Переносимая раскладка — именованный снимок** core-плагина Workspaces, который пишется в `.obsidian/workspaces.json` и меняется только по явному «Save layout». Этот файл **трекается**.
- В шаблоне снимка нет: раскладка зависит от того, чем инженер реально пользуется, и пустая заготовка тут хуже отсутствия. Создаётся на месте после развёртывания.

## Альтернативы

- **Коммитить живой `workspace.json`** — отклонён: шум в каждом коммите плюс конфликты слияния при работе с нескольких машин.
- **`workspace.json` + `git update-index --skip-worktree`** — отклонён: прячет шум, но Obsidian всё равно переписывает файл локально, и `git pull` с изменениями сверху упирается в «local changes would be overwritten». Флаг локальный — его пришлось бы заново ставить на каждом клоне.
- **Игнорировать и восстанавливать руками** — отклонён: раскладка не едет и теряется на новой машине, то есть решается ровно та задача, ради которой всё затевалось, — никак.

## Последствия

- **+** Раскладка переносится стабильным снимком, без шума в истории и без конфликтов.
- **−** Снимок надо пересохранять явно после изменения раскладки: автоматического обновления нет — это и есть цена отсутствия шума.
- **Операционно:** на новой машине снимок загружается через палитру команд (Workspaces), либо назначается стартовым.
