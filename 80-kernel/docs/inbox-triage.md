# Триаж инбокса (метод)

> Единственный владелец процедуры разбора `00-inbox/` (INV-2). Вызывается в двух кадансах: `/open` (день, режим **light**) и `/close` в день закрытия недели (режим **strict**). Это не два метода, а один в двух режимах.

Запись в инбоксе — **кандидат**: у неё ещё не присвоен род. Триаж = присвоить род и увести по адресу.

## Карта родов → куда

| Род записи | Куда |
|------------|------|
| **Кандидат в задачу** (есть тикет + предъявимый артефакт + переживает сессию) | карточка по [`task-discipline.md`](task-discipline.md) |
| **Задача-мелочь** (<15 мин, без предъявимого выхода) | сделать сразу или закрыть в трекере; карточку **не** заводить |
| **Работа без тикета** | завести тикет либо оставить в инбоксе до прояснения — карточка без тикета не заводится (ADR-0006) |
| **Знание о предметной области или системе** | `30-knowledge/<тема>/` |
| **Архитектурное решение** | `/archgate` → ADR (`80-kernel/stele/` или `10-governance/projects/<проект>/adr/`) |
| **Урок о работе с агентом** | `70-memory/` + строка в `MEMORY.md` |
| **Семя текста / черновик** | `20-library/drafts/`; короткая мысль — `20-library/notes/` |
| **Шум** | удалить; при сомнении → `90-archive/` |

## Режимы

**light (день, `/open`).** Присвоить род свежим записям и увести по адресу. Неопределённое — **оставить** в инбоксе, оно ещё исследуется. Цель — не дать свежему накопиться, а не вычистить до дна.

**strict (неделя, `/close` в день закрытия недели).** Тот же проход плюс **форсирующая функция**: запись, провисевшая нерешённой **больше недели**, уезжает в `90-archive/`. Не жалеть: если за неделю род так и не присвоен, ценность записи не подтверждена. Архив обратим — это холод, не удаление, — но из активного внимания запись уходит.

## Зачем нужен strict

- **Окно исследования с тайм-боксом.** Неделя — окно; дальше решение «беру или отпускаю», устойчивое к уже потраченному вниманию.
- **Лимит незавершённого.** Нерешённая запись — замороженный капитал: она тянет внимание каждый раз, когда попадается на глаза. Без форса инбокс растёт как склад.
- **Присвоение рода.** Strict заставляет назвать род или признать, что его нет. «Не знаю, что это» через неделю означает «это шум».

Окно в одну неделю — параметр, привязанный к недельному проходу. Меняется правкой этого файла, а не молчаливым послаблением.
