# 20-library — письмо

Здесь живёт то, что пишется **своими словами**: не выдержки из документации, а собственное понимание и тексты, адресованные людям.

| Каталог | Что | Writer |
|---|---|---|
| `notes/` | заметки: короткая мысль, разбор, наблюдение по ходу работы | engineer-writer |
| `drafts/` | черновики адресованных текстов: RFC, разбор инцидента, страница вики, ответ коллеге | engineer-writer |

**Цепочка:** захват в `00-inbox/` → триаж присваивает род → заметка в `notes/` → выросла в адресованный текст → `drafts/` → опубликовано (вики, MR, письмо) → в карточке остаётся ссылка на публикацию.

**Граница с `30-knowledge/`:** здесь — **твои формулировки и тексты для людей**; там — **знание о предмете** (как устроен сервис, какие есть ограничения, где документация). Разбор инцидента, который ты пишешь для команды, — сюда; вывод из него о том, как ведёт себя система, — туда.

**Writer-ownership (INV-19).** Этот слой ведёт инженер. Агент правит здесь только по явной просьбе — проза, написанная за тебя, не является твоим пониманием и на следующей встрече это выяснится.

**Публикация вовне.** Текст, который уедет коллегам, — на языке команды (обычно английский), без пересказа чужой документации вместо ссылки на неё, и с раскрытием использования ИИ, если этого требует политика работодателя.
