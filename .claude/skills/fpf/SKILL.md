# /fpf — Загрузка первых принципов

Запрос: $ARGUMENTS

> Источник — **только локальный submodule** `.principles/fpf` (`Grep`/`Read`, офлайн, версия зафиксирована коммитом). Внешний сервис семантического поиска в этом контуре **не подключается** — [[ADR-0011-fpf-submodule-no-mcp|ADR-0011]]: рабочий запрос не уходит наружу.
> Карта и перевод терминов — `.principles/README.md`.

## Режимы (определить по запросу)

| Режим | Триггер | Что делать |
|---|---|---|
| **lookup** | код паттерна (`A.7`, `B.5`) или конкретный термин | `Grep` по submodule → точная секция → объяснить инженерным языком |
| **review** | «проверь», «сверь с принципами», артефакт на проверку | загрузить артефакт + релевантные принципы → сверка пункт за пунктом → расхождения |
| **design** | «спроектируй», «как правильно устроить» | подобрать применимые паттерны (границы A.1, состав A.6, различения A.7, цикл B.5) → рекомендации |
| **characterize** | «сравни», «оцени варианты» | A.17–A.19: критерии → индикаторы → оценка всех вариантов по **одной** шкале |
| **teach** | «объясни», «что это», «введение» | обзор: что, зачем, ключевые блоки — инженерным языком без жаргона |
| **diagnose** | «что не так», «какие принципы нарушаю» | описание работы → расхождения с принципами → конкретно: принцип + где нарушен |

Неясно → `lookup`.

## Алгоритм

1. Определить режим.
2. Найти точное место: `Grep` по `.principles/fpf/` (обзор — `Readme.md`, спецификация — `FPF-Spec.md`).
3. Показать принципы **с привязкой к задаче** и ссылкой на источник (файл + секция). Принцип без привязки к текущему решению — цитата, а не аргумент.
4. Если применимого принципа не нашлось — **сказать это**, а не подогнать близкий. Отсутствие принципа тоже результат.

## БЛОКИРУЮЩЕЕ — No-Jargon (INV-6)

Каждый термин фреймворка в выводе сопровождается инженерным эквивалентом — в скобках или вместо. Таблица перевода — `.principles/README.md`.

Неизвестный термин: перевести по контексту и пометить `(FPF: <оригинал>)`.

**Тест перед выводом:** есть ли в тексте термин, непонятный инженеру, который фреймворка не читал? Есть → перевести. Жаргон здесь — не признак строгости, а способ не быть проверенным.
