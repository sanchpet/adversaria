# /open — Открытие дня (INV-9, масштаб «день»)

Роль: ассистент в рабочем vault. Тон инженерный (INV-16).

1. **Детектор ритма** — `bash 80-kernel/scripts/orz-check.sh`. Есть флаг (незакрытый день, залежавшийся инбокс, незакоммиченное) — разобрать **до** планирования. Тот же детектор висит на `SessionStart` (INV-5).

2. **`date`** — сверить с ритмом из `80-kernel/config.md` (секция «Ритм»): рабочий день или нет, день из дома или из офиса, сегодня ли `week_close_day`.

3. **Вчерашний журнал** — прочитать последний `10-governance/sessions/*.md`, секцию «Завтра начать с». Это вход дня, а не воспоминание: если там тема вместо решения и действия, вчера закрыли плохо — сказать об этом.

4. **Триаж инбокса (light)** — по `80-kernel/docs/inbox-triage.md`: присвоить род свежим записям, увести по адресу. Неопределённое **оставить** — оно ещё исследуется.

5. **Активные задачи** — `10-governance/tasks/` где `status` ∈ {`in-progress`, `blocked`}. Показать таблицей: тикет, что осталось, кого или что ждём. Для `blocked` — назвать, кто владелец блокера: задача, которая ждёт не тебя, не должна занимать место в плане дня.

6. **DayPlan** → `10-governance/plans/current/dayplan-YYYY-MM-DD.md` из скелета `80-kernel/scaffolds/dayplan-tmpl.md`.
   - **Ёмкость — из конфига** (`focus_capacity`). Сверх неё не верстать: план, который не помещается в день, перестаёт читаться на второй неделе. Если задач больше ёмкости — не «уплотнить», а **назвать, что не войдёт**.
   - Задачи таблицей со светофором-приоритетом. Светофор = приоритет, **не статус** (статус живёт в карточке).
   - «Что сегодня» — следующее действие, а не тема.
   - Встречи и окна разворачивать, только если есть что заносить (INV-3).

7. **Журнал сессии** → `10-governance/sessions/YYYY-MM-DD.md` из `80-kernel/scaffolds/session-tmpl.md` (пустой, наполняется по ходу).

8. **Коммит.**

Не делать: заведение карточек скопом «на всякий случай», перенос статусов из трекера, вёрстку дня на объём, который в него не помещается.
