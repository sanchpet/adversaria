# Память — индекс

> Индекс памяти агента: строка на память, загружается в контекст каждой сессии (ADR-0005). Содержимое памятей — в отдельных файлах рядом, **не здесь**.

Одна память — один файл — один факт. Frontmatter: `name`, `description` (по нему решается релевантность при recall), `metadata.type`.

| type | Что сюда |
|---|---|
| `user` | кто такой инженер: роль, зона ответственности, предпочтения в работе |
| `feedback` | как со мной работать: поправки и подтверждённые подходы — **обязательно с «почему»** |
| `project` | текущая работа, цели и ограничения, не выводимые из кода и истории git |
| `reference` | указатели на внешнее: вики, дашборды, рансбуки, чаты |

**Что сюда не пишем:** то, что уже записано в репозитории (структура кода, история git, `CLAUDE.md`); то, что важно только в этом разговоре; и — по INV-22 — любые значения секретов и персональные данные.

**Память стареет.** Запись, названная неверной, удаляется, а не помечается устаревшей: память читается как истина, и «почти верная» память хуже отсутствующей.
