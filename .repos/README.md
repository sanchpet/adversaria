# .repos — клоны рабочих репозиториев

Точка монтирования для клонов репозиториев, с которыми идёт работа. **Содержимое вне git этого vault** (`.gitignore`): у каждого клона свой remote и своя история; смешивать их с историей vault нельзя.

Трекается только этот файл и раскладка.

## Раскладка

По источнику и группе, как в самом хостинге:

```
.repos/
  <group>/<repo>          # клон
  <group>/<subgroup>/<repo>
```

Карта «что клонировано и зачем» — в `80-kernel/config.md`, секция «Репозитории». Держать её актуальной стоит: через полгода каталог с полутора десятками клонов сам себя не объясняет.

## Почему dot-каталог

Obsidian игнорирует каталоги, начинающиеся с точки. Это и нужно: код в графе заметок, поиске и quick-switcher — шум. Агенту и редактору кода каталог виден нормально.

## VSCode

Вложенные репозитории под ignored-путём родителя редактор по умолчанию показывает тускло и не даёт по ним Source Control. Явная регистрация — в `.vscode/settings.json` → `git.scanRepositories`. Новый клон → дописать строку туда.
